阿系呦影音剪輯

在瀏覽器裡直接剪 MP3 和 MP4，檔案不會上傳到任何地方。

點這裡選擇檔案，或把 MP3 / MP4 拖進來

步驟：① 在波形上拖曳選一段 → ② 按剪刀「只保留選取」或「刪除選取」（可重複剪很多次，剪錯按復原）→ ③ 匯出。單擊波形從該處播放，滾輪縮放，Shift + 滾輪左右捲動。

快捷鍵
K✂ 只保留選取 Delete✂ 刪除選取（前後自動接起來） Ctrl+Z / Ctrl+Y復原 / 重做 Space播放 / 停止選取範圍 I O把目前播放位置設為起點 / 終點（停止時用游標位置） ← →微調目前的邊（橘框那個）0.01 秒；加 Shift 為 0.1 秒、加 Ctrl 為 1 秒 Tab切換要微調起點還是終點 + -放大 / 縮小 Z 0縮放到選取 / 顯示全部
